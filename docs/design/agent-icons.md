# Coding-agent icon selection

Status: design direction recorded 2026-11-19; not yet implemented.

- Show unselected agent marks in monochrome.
- Show the selected agent’s brand artwork in color, retaining its selection checkmark.
- Apply the same distinction to picker rows and the selected agent chip across Apple and web.

  accent rather than inventing and claiming an official brand color.
