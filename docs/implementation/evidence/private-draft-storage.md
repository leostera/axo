## Trust/storage boundaries implemented

- `AxodChatDraftArchive` parses bounded private binary v1 into a trusted archive. Its magic/version, UTF-8 lengths, record counts, exact EOF, nonzero IDs, unique conversations/commands and aggregate text budget are closed. Array/object-key shadowing cannot silently discard text. Logical draft scope excludes runtime/host generations; pending records preserve complete original targets/command/revision but **never grant dispatch authority**. Empty text rows are refused; a pending record can survive without a text row after explicit local clearing. Limits retain 32 draft slots/32 pending records, 64KiB per draft/1MiB aggregate; encoded input is capped at 2MiB independently of RPC bounds.
- `AxodChatDraftStore` requires an already-existing approved local root. It walks each component with `openat`/`O_NOFOLLOW`, pins and revalidates directory identity, and requires owned private directories and regular single-link 0600 files. It rejects unsafe, opaque, corrupt, oversized, FIFO or symlinked input rather than overwriting it. It neither provisions arbitrary paths nor migrates legacy files.
- Each read/write holds a validated transaction-local nonblocking flock lease, not a PID or inventory claim. Explicit unlock precedes FD close, including duplicated descriptors. Exact original-byte checkpoints are store-bound; changed data or another instance's checkpoint refuses a stale write. A new archive revision is required. No automatic merge/retry occurs.
- Commit creates its own 0600 exclusive same-directory temporary file, writes/flushes, rechecks the original bytes, root/lock/stage identities and atomically renames/flushes the directory. Cleanup authority is only the still-open uncommitted creation descriptor. Post-rename files are never reclaimed. I/O failure permanently fences subsequent writes from that store; an uncertain result preserves original/replacement data and grants no retry. Cooperative leases do not exclude malicious/unmanaged same-user writers.
- Pre/post-rename failure injection exists only under `AXO_DRAFT_STORE_FIXTURE`; it is absent from shipped builds. No canonical JSONL, model call, local/cloud command or receipt is created by this primitive. Diagnostics select static stages/classes and contain no bodies/credentials.
